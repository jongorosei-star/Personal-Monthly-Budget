# 💰 Personal Expense Tracker CLI

Aplikasi Personal Expense Tracker berbasis Command Line Interface (CLI) menggunakan Python dan JSON sebagai database sederhana.

## ✨ Fitur

- ✅ Tambah transaksi pengeluaran
- ✅ Lihat semua transaksi
- ✅ Hapus transaksi
- ✅ Kelola budget per kategori
- ✅ Backup database otomatis
- ✅ Penyimpanan data menggunakan JSON
- ✅ Tampilan CLI yang sederhana dan mudah digunakan

---

## 📂 Struktur Project
Personal-Expense-Tracker/ │ ├── main.py          # Program utama ├── crud.py          # Operasi CRUD transaksi ├── budget.py        # Manajemen budget ├── backup.py        # Backup database ├── ui.py            # Tampilan menu CLI ├── database.json    # Database penyimpanan └── README.md        # Dokumentasi project


#Cara menjalankan

git clone https://github.com/jongorosei-star/personal-expense-tracker.git

cd personal-expense-tracker

python main.py
